## 🚀 Projetos em Destaque

**Assistente Virtual de Leitura de Documentos com IA (RAG)**
Aplicação de Retrieval-Augmented Generation para conversar com o conteúdo de PDFs. Pipeline completo (loading, chunking, embeddings, indexação vetorial, geração com citação de fontes), com suporte a OpenAI API ou modelos locais via Ollama.
`Python` `LangChain` `FAISS` `Streamlit` `Docker` `OpenAI API` `Ollama`
[código](https://github.com/maurofe2003-design/Assistente-virtual-de-leitura-de-documentos-com-IA)

**API de Controle Financeiro**
API REST para controle financeiro pessoal com cadastro de receitas, despesas, categorias e relatórios. Arquitetura em camadas, com 24 testes automatizados.
`Python` `FastAPI` `SQLAlchemy` `Alembic` `Pytest` `Docker`
[código](https://github.com/maurofe2003-design/-API-de-Controle-Financeiro)

**ShopAPI — Plataforma de E-commerce**
Cadastro e autenticação de usuários, gerenciamento de produtos, carrinho e pedidos via APIs REST.
`Java` `Spring Boot` `HTML` `REST API`
[demo](https://shopapi-git-master-maurofe2003-designs-projects.vercel.app) · [código](https://github.com/maurofe2003-design/shopapi)

**LojaFlex — Loja Virtual de Perfumes**

**NOX BLACK — Sistema para Barbearia**
