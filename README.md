# 🚀 Projetos em destaque

### 🤖 Assistente Virtual de Leitura de Documentos/PDFs com IA (RAG)
Aplicação de Retrieval-Augmented Generation para conversar com o conteúdo de arquivos PDF. Pipeline completo (loading, chunking, embeddings, indexação vetorial e geração com citação de fontes), com suporte à OpenAI API ou modelos locais via Ollama. Interfaces web (Streamlit) e CLI compartilhando a mesma lógica de negócio, com testes unitários e execução via Docker.

`Python` `LangChain` `FAISS` `Streamlit` `Docker` `OpenAI API` `Ollama`

`Python` `FastAPI` `SQLAlchemy` `Alembic` `Pytest` `Docker`

### 🛒 ShopAPI — Plataforma de E-commerce
